# Contribution and AI Disclosure

This document separates the student's reported work from AI-assisted implementation and documentation.

## Student Contributions
Based on the project discussion, the student:
- Proposed the button-based communication project concept.
- Identified the need for predefined messages.
- Selected and obtained the listed hardware components.
- Assembled the Arduino, buttons, resistors, jumper wires and I2C LCD.
- Connected the three button inputs and pull-down resistors.
- Uploaded and exercised the sketch on the physical prototype.
- Reported observed hardware behaviour and participated in troubleshooting.
- Confirmed the message mapping used in the project discussion.

Only claim tasks actually performed by the student in a formal submission.

## AI-Assisted Work
AI assistance was used to:
- Explain digital input states, floating inputs, pull-down resistors and button wiring.
- Explain individual presses and simultaneous combinations.
- Structure/refine the Arduino sketch, including debouncing and LCD update handling.
- Prepare the README, pinout, wiring guide, algorithm, architecture, design decisions and testing documentation.
- Organize the repository package.

## Verification Responsibility
The student should review, understand, compile and test the source code before submission or demonstration. Reported observations are distinguished from formal test evidence. AI assistance does not establish independent hardware validation.

## Suggested Academic Disclosure
"Hardware selection, physical assembly, wiring and prototype operation were carried out by the student. AI assistance was used for code structuring, troubleshooting explanations and preparation of technical documentation. The final implementation should be reviewed and validated by the student."
